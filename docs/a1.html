The schematic is composed of three different pins going into their own resistor and LED. The current for each LED was set to 10 mA for a total of 30mA since the arduino max current is set to 40 mA. The calculations are included within the image, with the voltage for the red (pin 13) and green (pin 12) set to 2V with a calculated resistance of 300 ohms and 3.3V for the blue (pin 12) with a calculated resistance of 170 ohms.

Image of Circuit

When building the circuit, the resistor values calculated did not match the resistors given in the kit. Instead of 300 ohms, a resistor with 330 ohms was used, and for 170 ohms, 220 ohms were used.

// Setup function runs to setup the pins
void setup() {
  // initialize digital pin 13 as an output.
  pinMode(13, OUTPUT);
  // initialize digital pin 12 as an output.
  pinMode(12, OUTPUT);
  // initialize digital pin 11 as an output.
  pinMode(11, OUTPUT);
}
// Loop function that has the light show that will continue to repeat
void loop() {
  //Changes state of pin 13 to HIGH voltage level
  digitalWrite(13, HIGH);
  //Changes state of pin 12 to LOW voltage level
  digitalWrite(12, LOW);
  //Changes state of pin 11 to LOW voltage level
  digitalWrite(11, LOW);
  //Waits for 100 milliseconds
  delay(100);
  //Changes state of pin 13 to LOW voltage level
  digitalWrite(13, LOW);
  //Changes state of pin 12 to HIGH voltage level
  digitalWrite(12, HIGH);
  //Changes state of pin 11 to LOW voltage level
  digitalWrite(11, LOW); 
  //Waits for 100 milliseconds
  delay(100);
  //Changes state of pin 13 to LOW voltage level
  digitalWrite(13, LOW);
  //Changes state of pin 12 to LOW voltage level
  digitalWrite(12, LOW);
  //Changes state of pin 11 to HIGH voltage level
  digitalWrite(11, HIGH); 
  //Waits for 200 milliseconds
  delay(200);
  //Changes state of pin 11 to LOW voltage level
  digitalWrite(11, LOW);
  //Waits for 100 milliseconds
  delay(100);
  //Changes state of pin 13 to HIGH voltage level
  digitalWrite(13, HIGH);
  //Changes state of pin 12 to HIGH voltage level
  digitalWrite(12, HIGH);
  //Changes state of pin 11 to HIGH voltage level
  digitalWrite(11, HIGH); 
  //Waits for 200 milliseconds
  delay(200);
  //Changes state of pin 13 to LOW voltage level
  digitalWrite(13, LOW);
  //Changes state of pin 12 to LOW voltage level
  digitalWrite(12, LOW);
  //Changes state of pin 11 to LOW voltage level
  digitalWrite(11, LOW); 
  //Waits for 300 milliseconds
  delay(300);
}
